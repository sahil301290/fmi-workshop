# FMI Workshop 2027

**Rapid Prototyping in Medical AI: From Multi-Sensor Data to Clinical Impact**

The inaugural Future Medicines Institute Workshop brings together academic, clinical and industry researchers to discuss the development, evaluation and real-world deployment of medical AI prototypes.

**Date:** Tuesday, 25 May 2027  
**Time:** 08:00–16:00 BST  
**Venue:** Ulster University, Belfast Campus, Northern Ireland  
**Workshop Chair:** Dr. Sahil Sharma, Future Medicines Institute, Ulster University

## Website

**https://sahil1301290.github.io/fmi-workshop/**

This website is hosted on GitHub Pages. It uses a single static HTML page and requires no build process or paid hosting.

## Repository files

- `index.html` — website content, styling and client-side interactions.
- `assets/favicon.svg` — website icon.
- `event.ics` — downloadable workshop calendar invitation.
- `README.md` — repository documentation.

## Deployment

In the GitHub repository, open **Settings → Pages** and configure:

- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/(root)`

Changes committed to `main` are published through GitHub Pages. No custom domain is configured; the repository must not contain a `CNAME` file.

## Registration and speaker proposals

Registration is not yet open. The displayed attendance fees and programme are provisional. The website does not process payments or store registration information.

Speaker expressions of interest are prepared as emails to the workshop chair. Invitations are decided by the organising committee; this is a presentation-based workshop with no conference proceedings.

## Maintenance

Update `index.html` to revise the programme, speakers, registration information, partners or other website content. Update `event.ics` if the event date or time changes.
